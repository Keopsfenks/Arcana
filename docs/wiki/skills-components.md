# Arcana native component catalog

All 125 entries below are independently registered factories/capabilities. There
are 57 mechanics, 23 predicates, 12 targeters, 9 mutators, 3 interceptors,
2 contributions, 4 aura components, 3 resource providers, 1 stat provider and
11 general triggers. The 12 existing Player trigger adapters remain available
through the legacy bridge. Provider contracts and reference-only identifiers
are not counted as extra implemented mechanics.

Each behavior lives in its own class/file. The composition root
`StandardSkillCatalog` only constructs/registers components; the separate
`StandardSkillExamples` helper copies disabled examples without overwriting
user files. Bundled filenames start with `_` and are ignored by the loader;
remove that prefix to validate/load a copy, then set `enabled: true` when ready.
See the [API guide](skills-api.md) and [YAML guide](skills.md).

## Authoring and help

The packaged `arcana-skills/schema-v2.json` is generated by `SkillSchemaWriter`
from the same option metadata native factories use for preflight, plus the
compiler's common/root option sets. CatalogCoverageTests compares the exact
bundled output. It checks supported keys/basic shapes and recognizes registered
native types; expressions, conditional requirements, numeric ranges, provider
capability and references are validated by `/arcana skills validate`. External
qualified components are left to the host compiler. Metadata type `value` is
intentionally broad because factories support literals/expressions or named
hooks with different shapes. The schema is not a replacement for compilation.

Use `/arcana skills inspect mechanic arcana:projectile` for metadata help or
`/arcana skills inspect <skill>` for source/revision/dependency information.

Common effect node options: `targeter`, `mutators`, `conditions`, `filters`,
`chance`, `delay`, `repeat`, `interval`, `on-failure`. Targeter-specific
`conditions` filter each freshly projected candidate; outer effect conditions
run after selected-role snapshots and variables have been refreshed. Repeat is
1..100; parallel fan-out 16; selection defaults 64 with maximum 256 recipients.
Numeric durations are seconds; explicit units are `ms`, `s`, `m`, `t`.

`variable` predicates accept a declared `var_name` binding, `data.field` or
`param.name`; nested map paths are bounded to 16 segments/256 characters. Missing
fields fail the condition. Typed equality never reparses incoming text as code.
For example, `binding: data.hand` plus `equals: OFF_HAND` selects off-hand consume
or shoot snapshots. Rich-text placeholders are inserted as literal components;
expanded values cannot inject new formatting tags.

## Tek dosyayla oyun içi test

Sunucuya kopyalanan `_v2_all-components-test.yml` dosyasının başındaki `_`
işaretini kaldır, `enabled: true` yap ve `/arcana skills reload` çalıştır.
`/arcana skills cast all_components_test` ile 57 mekanik sırayla denenir;
her adım numaralı DENENİYOR / UYGULANDI / ATLANDI mesajı verir, ardından
23 koşul EŞLEŞTİ / EŞLEŞMEDİ olarak gösterilir. Başarısız adım sonrakileri
durdurmaz. Çağrının başarılı olması, örneğin bir merminin gerçekten hedefe
isabet ettiği anlamına gelmez; oyun içindeki sonucu ayrıca gözlemle.

Test için tahta kılıç tut ve doğu (+X) yönünde üç blok öteye bir zırh askısı yerleştir.
Blok değiştirme ve teleport adımları dosyadaki açık seçeneklerle etkinleştirilir;
teleport koordinatlarını önce kendine göre düzenle. Aralık `pace.default`
ile ayarlanır. `/arcana skills reload` çalışan testi durdurur.

Aynı dosyanın başında 23 tetikleyicinin yönergesi ve ayrı olay modu bulunur.
`event_mode.default: true`, `triggers: [right_click]` ve aynı `event_label`
ile seçtiğin gerçek olayı test et; her seferinde tek tetikleyici kullan.
Bu mod efekt dizisini başlatmadan yakındaki yetkili oyuncuya olay mesajı verir.
Giriş/ölüm gibi gerçek olaylar otomatik üretilemez; `custom` ve `timer` için
API çağrısı gerekir. Normal teste dönmek için `event_mode.default: false` ve
`triggers: []` kullan. Herhangi bir başka beceri dosyası gerekmez.

## Runtime limits

Defaults/hard caps: 64 managed instances per actor and 4096 engine-wide,
4096 callbacks and 65536 applied steps per managed lineage, and 24 hours from
its first adoption. Source/caster/selected actors share those limits across
nested effects. Query limits are 256 loaded chunks, 4096 candidates and 65536
block samples; no automatic chunk loads or global entity scan. Normal roots
have 1024 applied steps and child-call depth 16. Timer interval is at least 1 tick.
Projectile speed is at most 64 blocks/tick, bounce count 100 and hit count 256.
A projectile's `duration` counts its movement ticks; stalled work has a bounded
100-actor-tick timeout per pending simulation step/initialization, within the
original managed lifetime deadline. Healthy queued global/region/entity handoffs
finish before simulation age expires. A required collision partition becoming
unavailable aborts the sweep; an overlapping neighboring entity hitbox is
discovered spatially and its state is read on its own owner.

The host's `config.yml` supports these positive settings, requiring restart;
values larger than their hard cap are rejected:

```yaml
skills:
  limits:
    managed-per-actor: 64
    managed-per-engine: 4096
    managed-callbacks: 4096
    managed-steps: 65536
    managed-lifetime-ticks: 1728000
```

Health costs leave 1 HP. Stun suppresses walking/supported jumping with exact
owned modifiers; it does not lock every action. Freeze stops refreshing and
then decays through vanilla behavior. `remove_potion` removes Arcana's timed
claims; holder contributions remain until holder removal, and external effects
require `external: true`. Title client timings are finite; source unload does
not send a delayed clear that could erase another plugin's later title.
`give_item` accepts at most 64 native stacks and reports overflow after preserving
already inserted items. Block edits obey native protection cancellation and
suppress fresh Arcana roots during their own generated protection events.

These limits have deterministic controlled-scheduler tests. Heap deltas are
non-GC estimates for test fixtures, not production Folia throughput guarantees.
Live Paper/Folia server startup and gameplay have not been tested here.
